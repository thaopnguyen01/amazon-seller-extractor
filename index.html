🏪 Amazon Seller Extractor

Instantly extract seller information from any Amazon product

Latest Release

⚡ Instant Extraction

Automatically detects and extracts seller name, ID, and storefront URL on any Amazon product page.

🌍 All Regions

Works on amazon.com, amazon.co.uk, amazon.ca, and amazon.co.jp with proper language/region handling.

🎯 Multi-Seller Support

Automatically detects multiple sellers and navigates to the offer-listing page to show all available sellers.

📋 Easy Copy

One-click copy buttons for seller name, ID, and URL. Perfect for quick data collection and analysis.

🤖 Smart Detection

Handles region-specific labels like "Sold by", "Shipper / Seller", and "Ships from" automatically.

🔗 Storefront Links

Direct access to seller storefronts with one click. Special handling for Amazon-direct sales.

✨ Key Features

✓ Auto-Detection

Automatically runs on product pages - no configuration needed.

✓ Multiple Sellers

Auto-navigates to offer-listing when multiple sellers detected.

✓ Amazon Handling

Properly detects when Amazon is the seller with special formatting.

✓ Region Aware

Preserves user's language/region setting (e.g., /-/en/ path on .co.jp).

✓ Copy to Clipboard

Quick copy buttons for each field with visual feedback.

✓ Extraction Details

See extraction method, raw data, domain, and timestamp for debugging.

📦 Installation (5 Minutes)

  1. Download the extension

    Click the download button above to get the latest version

  2. Extract the ZIP file

    Unzip the downloaded file to any folder on your computer

  3. Open Chrome Extensions

    Go to chrome://extensions/ in your browser address bar

  4. Enable Developer Mode

    Toggle the "Developer mode" switch in the top-right corner

  5. Load the extension

    Click "Load unpacked" and select the extracted amazon-seller-extractor folder

That's it! The extension is now installed and ready to use.
